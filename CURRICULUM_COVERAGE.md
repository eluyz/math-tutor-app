# Mathematics curriculum coverage — evidence overview

The project has mapped **64 Mathematics competency identifiers** to exercise families and known gaps. A mapping or generated task is not proof of complete syllabus coverage, and test success is not an independent certification of every original worksheet form.

## Evidence levels

| Type | Meaning |
| --- | --- |
| Competency mapping | Identifies a target skill or topic |
| Bounded generator support | Implements a controlled set of task forms |
| Partial coverage | Other forms or cases remain unsupported |
| Source witness | Independently checked original-form-to-app correspondence within a stated boundary |
| Independent QA | Independently recalculated answers, steps or grading cases in a specified cohort |

Historical checkpoints used denominators such as **64 mapped competencies**, **14 bounded** generator categories and separate source acceptance counts. They describe **specific dated snapshots**, not current global completeness. Never silently add distinct evidence types or recycle historical coverage percentages as current facts.

## Scope

The public Mathematics app includes bounded exercises for foundations, matrices, linear systems, sequences, functions, limits, differentiation, integration and selected multivariable topics. Original figure-specific and advanced syllabus forms may still be unverified.

The small Statistics pilot (ST-101 mean, ST-102 median, ST-103 population variance) is counted separately from Mathematics family/variant totals. ST-104 is not student-facing.
