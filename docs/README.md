## Documentation policy

- New repository-facing documentation: **English**.
- App prompts, lessons, hints and accessibility copy: **Polish and English**.
- Do not discard older test evidence or inflate adoption, coverage or review claims.
- A standalone generator is not a playable lesson until a separate approved UI release.
